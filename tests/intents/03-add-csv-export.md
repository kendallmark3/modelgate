# Intent: CSV export for the orders table
Outcome: a user can download the orders they are currently viewing as a CSV file.
Inputs: the existing orders list endpoint and the orders table component.
Outputs: an "Export CSV" button and a file with one row per visible order.
Success criteria: the file opens in a spreadsheet with correct columns; filters applied on screen apply to the export.
Constraints: follow the existing export pattern used on the customers page.
